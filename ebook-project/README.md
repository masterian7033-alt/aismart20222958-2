# 한국 메모리 반도체 산업 투자 전망 보고서 (3D Interactive E-Book)

> **Hallym Investment Equity Research · Semiconductor Division**  
> 삼성전자·SK하이닉스 중심 분석 — 사상 최대 실적 국면의 지속 가능성과 투자 리스크

본 프로젝트는 기관용 고품격 금융 리서치 보고서 PDF를 기반으로 실제 종이책을 넘겨 읽는 듯한 물리적 3D 페이지 플립 효과와 프리미엄 인터랙티브 독서 경험을 제공하는 웹 기반 독립형 E-Book 솔루션입니다.

---

## 1. 주요 기능 및 특징

1. **현실적인 3D 물리 페이지 넘김 (Realistic 3D Paper Flip)**
   - `StPageFlip` 물리 엔진을 탑재하여 마우스 모서리 드래그 시 실제 종이가 탄성 있게 휘어지고 빛과 그림자가 곡면을 따라 변화하는 자연스러운 3D 애니메이션을 제공합니다.
   - 단면 표지(Cover) 모드에서 책을 펼치면 양면 스프레드(Two-Page Spread)로 자동 전환됩니다.
   - 단단한 하드커버(앞표지/뒷표지)와 유연한 소프트 내지(본문)의 서로 다른 물리적 재질감을 완벽히 차별화했습니다.

2. **무손실 고해상도 벡터/래스터 렌더링 (2x Retina Crisp Quality)**
   - 원본 PDF의 복잡한 표, 그래프, 원형 차트, 미세 각주 및 참고문헌 번호가 흐려지지 않도록 $1,191 \times 1,684\text{ px}$ 고해상도 2x 레티나 규격으로 정밀 렌더링했습니다.
   - 원본 보고서의 모든 텍스트, 숫자, 서식, 참고문헌 35종의 배치와 비율을 100% 무손실 보존했습니다.

3. **증권사 리서치북 스타일의 다크 모던 테마 (Institutional Dark Theme)**
   - 차분하고 정돈된 흑백 및 딥 옵시디언(`Deep Obsidian`) 테마를 바탕으로, 책 자체에 시선이 집중되는 앰비언트 백라이트와 자연스러운 바닥 그림자 및 책등(Spine) 음영을 적용했습니다.

4. **직관적인 독서 인터페이스 (Reading Controls & Dock)**
   - **인터랙티브 목차(TOC) 서랍:** 보고서의 7개 핵심 챕터 및 참고문헌으로 1클릭 즉시 이동
   - **전체 페이지 썸네일 그리드:** 16개 전 페이지의 시각적 미리보기 지원
   - **반응형 진행률 게이지:** 읽고 있는 위치를 시각적으로 실시간 계산 및 원하는 위치 클릭 시 직접 점프
   - **Web Audio 실시간 페이퍼 사운드:** 네트워크 지연 없이 Web Audio API를 활용해 페이지를 넘길 때 부드러운 종이 넘김 소리를 즉각 합성 출력 (온/오프 토글 가능)
   - **확대(Zoom) 및 전체화면(Fullscreen):** 복잡한 표와 그래프를 더욱 크게 열람할 수 있는 125% 확대 뷰 지원
   - **원본 PDF 다운로드:** 보고서 원본 파일 즉시 저장 가능

5. **완전한 오프라인 독립 실행 (100% Portable & Self-Contained)**
   - 외부 CDN 서버에 의존하지 않고 모든 CSS, JS 라이브러리(`page-flip.browser.js`), 고해상도 이미지, 원본 PDF를 상대 경로로 프로젝트 폴더 내에 패키징하여, 인터넷이 연결되지 않은 환경이나 타 PC로 폴더를 통째로 복사해도 즉시 구동됩니다.

## 3. 실행 방법 (Quick Start)

### 방법 1. 브라우저로 직접 열기 (가장 간편)
- `index.html` 파일을 더블클릭하거나 크롬/사파리/엣지 등 최신 웹 브라우저로 드래그 앤 드롭하여 즉시 실행할 수 있습니다.

### 방법 2. 로컬 웹 서버 실행 (권장)
터미널에서 `ebook-project` 디렉토리로 이동 후 다음 명령어를 실행합니다:

```bash
cd /Users/a14003652473024/antigravity/ebook-project
python3 -m http.server 8080
```
웹 브라우저를 열고 `http://localhost:8080`에 접속하면 최상의 부드러운 프레임으로 열람할 수 있습니다.

## 4. 조작 단축키 (Keyboard Shortcuts)

| 키 | 동작 설명 |
| :--- | :--- |
| **`→` (오른쪽 화살표), `Space`, `PageDown`** | 다음 페이지로 3D 넘기기 |
| **`←` (왼쪽 화살표), `PageUp`** | 이전 페이지로 3D 넘기기 |
| **`Home`** | 첫 페이지(표지)로 바로 이동 |
| **`End`** | 마지막 페이지로 바로 이동 |
| **`Esc`** | 열려 있는 목차 서랍 / 썸네일 모달 닫기 및 확대 해제 |
| **마우스 드래그 / 클릭** | 페이지 모서리를 마우스로 집어서 실제 종이처럼 넘기기 |
